# Muffle v0.1.1

Muffle v0.1.1 is the first public release of the native C++17 command
wrapper.

The earlier `v0.1.0` tag was created during release validation, but no
release or assets were published from it. This release includes packaging
workflow corrections discovered by its failed publication attempt.

## Included

- Quiet successful execution with concise success summaries.
- Combined stdout/stderr capture, configurable failure tails, verbose
  streaming, persistent logs, and child exit-status propagation.
- POSIX process execution with best-effort SIGINT/SIGTERM forwarding and
  bounded escalation for children that ignore termination.
- macOS and Linux release archives for the tested arm64 and x86_64 runners.
- Debian packages for Linux architectures built and installation-tested in
  the release workflow; RPM packages are installed and exercised in Fedora.
- CMake install support and the `muffle(1)` manual page.

## Limitations

Muffle does not provide native Windows support, interactive TTY behavior,
separate child output streams, log redaction, or guaranteed cleanup for
processes that escape the child's process group. Read the documentation for
complete details.

## Verify downloads

Download `SHA256SUMS` alongside an asset and run:

```sh
sha256sum -c SHA256SUMS
```

The release workflow also generates GitHub build provenance attestations for
uploaded assets. See the release workflow and the security documentation for
verification details.
