# Muffle v0.1.2

Muffle v0.1.2 fixes process cleanup when a child closes stdout and stderr
before it ignores a termination signal. Muffle now escalates and reaps that
child while the parent is blocked waiting for it.

## Included

- Fix SIGINT/SIGTERM escalation after the capture pipe reaches EOF.
- Add a synchronized integration test for the closed-stream case.
- Preserve the CLI, log, exit-status, and package behavior from v0.1.1.

## Platforms and packages

The release workflow builds and tests macOS arm64/x86_64 and Linux
arm64/x86_64 archives, Debian packages, and RPM packages. See the current
[installation guide](../installation.md) for download instructions.

## Verify downloads

Verify release assets against `SHA256SUMS`. The GitHub Actions workflow also
produces provenance attestations for release assets.
