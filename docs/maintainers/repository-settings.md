# Repository settings

This page records the intended and recently verified public repository
configuration for `Thavarshan/muffle`. Live GitHub settings remain
authoritative.

- Visibility: public
- Default branch: `main`
- License: MIT
- Issues: enabled
- Discussions: enabled
- Wiki and Projects: disabled
- Forking: allowed
- Branch protection: none, allowing maintainer direct pushes to `main`
- Dependabot security updates: enabled
- Dependabot alerts: enabled
- Secret scanning and push protection: enabled
- Private vulnerability reporting: enabled

The repository does not require PRs for maintainer changes. External
contributors can submit PRs. CI runs on pushes, pull requests, and manual
workflow dispatch.

Settings are managed through repository Settings or the authenticated
GitHub CLI. Check Security > Code security and analysis for security feature
availability. Feature availability can depend on repository eligibility and
GitHub plan; do not enable paid capabilities. Discussions categories are
managed in the repository's Discussions UI.
