# Governance

Muffle is currently maintained by its repository owner, Jerome
Thayananthajothy. The maintainer makes final decisions about project scope,
behavior, releases, and repository administration. There is no committee or
formal organization.

Contributions and proposals are welcome, but acceptance is not guaranteed.
External pull requests are reviewed by the maintainer. Routine maintainer
changes may be committed directly to `main`. The maintainer may delegate
review or seek community input when useful.

The project uses the MIT License and the Contributor Covenant Code of
Conduct. Community members can propose changes through GitHub Issues and
Discussions.
