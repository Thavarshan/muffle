# Support

For a reproducible defect, use the
[bug report form](https://github.com/Thavarshan/muffle/issues/new/choose).
For a use case or behavior proposal, use the
[feature request form](https://github.com/Thavarshan/muffle/issues/new/choose).
For a correction to project documentation, use the
[documentation form](https://github.com/Thavarshan/muffle/issues/new/choose).

Please include the Muffle version, operating system, exact reproduction,
expected and actual behavior, exit code, and sanitized logs where relevant.
Do not publish secrets, credentials, or private data. Use GitHub private
vulnerability reporting for suspected security issues instead of a public
issue.

Community discussion is available in the repository's GitHub Discussions.
Support is provided by project maintainers and community contributors on a
best-effort basis; no response time is guaranteed.
